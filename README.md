# China-Regional-Grid-EMT-CaseB-DIgSILENT2022
EMT simulation case of a desensitized 42-bus regional power system in China, modeled in DIgSILENT PowerFactory 2022. The system includes one equivalent external grid, one thermal power unit, nine wind power plants, 27 transmission lines, and 22 transformers, with renewable generation contributing more than 50% of the total power output.
