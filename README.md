# China Regional Grid EMT Case B (DIgSILENT 2022)

## Overview
This repository contains an electromagnetic transient (EMT) simulation case based on a desensitized 42-bus regional power grid in China, implemented in DIgSILENT PowerFactory 2022.

## System Description
- **Buses:** 42
- **External Grid:** 1 equivalent source
- **Thermal Power Unit:** 1
- **Wind Power Plants:** 9
- **Renewable Power Share:** >50% of total generation
- **Transmission Lines:** 27
- **Transformers:** 22
- **Voltage Levels:** 35 kV, 220 kV, 525 kV

The model has been anonymized to protect sensitive grid information while preserving the electrical characteristics relevant to EMT studies.

## Files
- `CaseB_EMT_DIgSILENT2022.pfd` — PowerFactory project file (v2022)
- `docs/` — System single-line diagram, parameter tables, and data sheets
- `examples/` — Sample EMT simulation scenarios

## Requirements
- DIgSILENT PowerFactory 2022 or later
- License supporting EMT simulation
